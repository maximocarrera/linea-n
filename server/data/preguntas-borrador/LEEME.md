# Preguntas borrador

Preguntas nuevas para revisar antes de que entren al juego. El juego NO lee esta carpeta.

- Revisarlas: `npm run db:borradores` (valida el formato y avisa si la consigna ya existe en el juego).
- Ver el resumen y las dudas: `REVISAR.md`.
- Aprobar una: moverla a `server/data/preguntas/` y correr `npm run db:import` (o pedírselo a Claude).
- Descartar una: borrar el archivo.
